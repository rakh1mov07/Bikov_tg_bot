#  Быков Бот

Telegram бот, отыгрывающий роль **Быкова Андрея Евгеньевича** из российского сериала «Интерны» (в исполнении Ивана Охлобыстина).

Бот циничен, груб и саркастичен — точно как в сериале. Помнит контекст разговора, реагирует на повторные вопросы взрывом злости и никогда не выходит из роли.

---

##  Нейросеть

Работает на базе **Meta Llama 3.1 8B Instruct** — локально через **LM Studio**.  
Никакие данные не уходят в интернет — всё крутится на твоём компьютере.
